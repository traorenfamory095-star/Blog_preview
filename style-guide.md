# Guide de style Front-end

## Mise en page

Les designs ont été créés pour les dimensions suivantes :

* Mobile : 375 px
* Desktop : 1440 px

> 💡 Ces dimensions correspondent uniquement aux tailles utilisées pour concevoir le design. Assurez-vous que le contenu soit responsive et respecte les exigences d'accessibilité WCAG en testant votre site sur une gamme complète de tailles d'écran, de 320 px jusqu'aux grands écrans.

## Couleurs

* Yellow : hsl(47, 88%, 63%)

* White : hsl(0, 0%, 100%)

* Gray 500 : hsl(0, 0%, 42%)
 
* Gray 950 : hsl(0, 0%, 7%)

## Typographie

### Texte principal

* Taille de police (paragraphe) : 16 px

### Police

* Famille : Figtree
* Graisses : 500, 800
